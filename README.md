# 👋 Hi, I'm Alex

### 🛠️ What I build

Tools for the AI-assisted future. Systems that compose. Infrastructure that doesn't surprise you.

---

### 📐 The shape of things

Started in **embedded systems** — where every byte matters and bugs crash hardware, not just processes.

Moved through **iOS** — mobile at scale, real users, real constraints.

Went deep on **functional programming** — type systems as documentation, composition as architecture, reasoning about code without running it.

Now building **AI/ML infrastructure** — because the same principles that make distributed systems reliable apply to making LLMs useful.

The common thread: **systems where correctness matters**.
